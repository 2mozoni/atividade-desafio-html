🌐 Portfólio / Currículo Web Semântico
Este projeto consiste na criação de uma página web de Portfólio / Currículo profissional, desenvolvida com foco total na estrutura semântica do HTML5. O objetivo principal é demonstrar boas práticas de organização de dados, acessibilidade e estruturação de elementos web segundo o modelo fornecido.

Estrutura do Projeto

💼 Visão Geral
A página foi construída para apresentar as informações profissionais de um desenvolvedor, dividida de forma clara e objetiva em seções acessíveis através de menu de navegação por âncoras internas.

🎯 Funcionalidades e Estrutura
Cabeçalho & Navegação (<header>, <nav>):

Título principal contendo o nome e cargo do desenvolvedor.

Menu de navegação rápido apontando diretamente para as seções da página (#sobre, #projetos, #contato).

Seção "Sobre Mim" (<section>):

Imagem de perfil dimensionada exatamente em 150x150 pixels.

Texto de apresentação detalhando formação acadêmica e objetivos.

Lista não ordenada (<ul>) destacando as Minhas Habilidades.

Seção "Meus Projetos" (<section>, <table>):

Tabela estruturada semanticamente (<thead>, <tbody>, <tr>, <th>, <td>) contendo:

Nome do Projeto

Tecnologias Utilizadas

Status do Projeto

Link funcional para o repositório/demonstração.

Seção "Entre em Contato" (<section>, <form>):

Agrupamento de formulário utilizando <fieldset> e <legend> ("Dados do Contato").

Campos de entrada para Nome e Email com <label> devidamente vinculados (for e id).

Menu suspenso (<select>) para escolha do Assunto.

Campo de texto em área aberta (<textarea>) para Mensagem.

Botão de submissão do formulário.

Rodapé (<footer>):

Declaração de direitos autorais utilizando o caractere especial HTML (&copy;).

Informações de contato direto (E-mail e Telefone).

🔧 Especificações Técnicas
Linguagem: HTML5 puro (padrão semântico e estruturado).

Acessibilidade & Semântica: Uso apropriado de tags de bloco e seção (<header>, <nav>, <main>, <section>, <table>, <fieldset>, <footer>).

Navegação Interna: Links âncoras (href="#id") para facilidade de rolagem.

Formulários Acessíveis: Vínculo explícito entre rótulos (<label>) e campos de formulário (<input>, <select>, <textarea>).
